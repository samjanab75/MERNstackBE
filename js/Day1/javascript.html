JavaScript is a programming language used to make websites interactive, dynamic and responsive.

3. Expressions

An expression is something that produces a value. 

10 + 20
x + y
a * b
age >= 18
name + " Kumar"
x = 10

Types of Expressions

  • Arithmetic Expression
  • Comparison Expression
  • Logical Expression
  • Assignment Expression
  • String Expression
  • Conditional Expression

4. Statements

A statement is an instruction given to JavaScript to perform an action. 

let name = "Samjana";

const age = 24;

console.log(name);

if (age >= 18) {
    console.log("Adult");
}

for (let i = 0; i < 5; i++) {
    console.log(i);
}

Types of Statements

  1. Variable Declaration
  2. Assignment Statement
  3. if Statement
  4. if...else Statement
  5. switch Statement
  6. for Loop
  7. while Loop
  8. do...while Loop
  9. break Statement
  10. continue Statement
  11. return Statement

5. Expression vs Statement

Expression

Produces a value. 

10 + 5
age > 18
x * 2

Statement

Performs an action. 

let x = 10;
console.log(x);

if (age > 18) { }

6. Rules for Variable Names

  • Can contain letters.
  • Can contain numbers, but not at the beginning.
  • Can use underscore _.
  • Can use dollar sign $.
  • Cannot start with a number.
  • Cannot contain spaces.
  • Cannot use reserved keywords.
  • Variable names are case-sensitive.
