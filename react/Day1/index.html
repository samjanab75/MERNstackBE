Task 1

React Basics

1. What is React?

React is a JavaScript library used to build user interfaces, especially interactive web applications. It lets us create the UI using small reusable components.

Easy to say: “React helps us build interactive websites using reusable components.”

2. Why do we use React?

We use React to create fast, interactive and maintainable user interfaces. It makes large UI projects easier to organize because the UI can be divided into components.

Easy to say: “React makes UI development easier by using reusable components and efficient updates.”

3. Is React a library or framework?

React is a JavaScript library for building user interfaces. It mainly focuses on the UI layer. Developers can add other libraries for routing, data fetching and other needs.

Remember: React = Library, not a full framework by itself.

4. Main features of React

Important features include components, JSX, declarative UI, one-way data flow, state and props, reusable UI, and efficient DOM updates through React’s rendering and reconciliation process.

Shortcut: Components + JSX + State/Props + Declarative UI + Efficient Updates.

5. What is a Single Page Application (SPA)?

A SPA is a web application where the browser loads the main page and JavaScript updates the displayed content without requiring a full page reload for every navigation.

Example: In a React app, changing from Home to About can update the UI without refreshing the whole browser page.

6. What is declarative UI?

Declarative UI means we describe what the UI should look like for a particular state. React handles the detailed DOM changes needed to reach that result.

Easy to say: “I describe what I want; React handles how to update it.”

Task 2

Components

1. What is a Component?

A component is an independent, reusable part of a React UI. It usually contains the logic and UI for one part of the application.

Examples: Navbar, Button, LoginForm, ProductCard.

2. Why do we use Components?

Components divide a large UI into smaller pieces. This makes code easier to understand, reuse, test and maintain.

Instead of one huge file, we create small meaningful parts.

3. What is a Functional Component?

A functional component is a JavaScript function that returns React UI, usually written with JSX.

function Welcome() {
  return <h1>Hello React</h1>;
}
Function → returns JSX → React displays it.

4. Component-Based Architecture

It is an approach where an application is built by combining small, independent and reusable components.

Think of a website like LEGO: each component is one reusable block.

5. What is a Component Tree?

A component tree shows the parent-child relationship between components.

App
├── Navbar
├── Home
│   ├── Hero
│   └── ProductCard
└── Footer
App is the parent. Navbar, Home and Footer are its children.

6. Why capital letter?

React uses capitalization to distinguish custom components from normal HTML elements. <Header /> is treated as a component, while <header> is an HTML element.

Custom React component names should start with a capital letter.

7. What is a reusable component?

A reusable component is designed so the same component can be used in multiple places, often with different data through props.

function Button({ text }) {
  return <button>{text}</button>;
}

// <Button text="Login" />
// <Button text="Register" />
Write once → use many times.

Task 3

JSX

1. What is JSX?

JSX stands for JavaScript XML. It is a syntax extension that lets us write HTML-like UI syntax inside JavaScript code.

JSX makes React UI code easier to read and write.

2. Why use JSX?

JSX keeps the UI structure close to the JavaScript logic that controls it. It also makes component code more readable.

JSX helps us describe UI clearly inside a component.

3. Is JSX HTML?

No. JSX looks similar to HTML, but it is JavaScript syntax. React tooling transforms JSX into JavaScript that React can use.

HTML and JSX look similar, but JSX is not plain HTML.

4. JavaScript expressions inside JSX

Use curly braces { } to place JavaScript expressions inside JSX.

const name = "Sam";

return <h1>Hello {name}</h1>;
Curly braces tell JSX: “Evaluate this JavaScript expression.”

5. Why className instead of class?

In JSX, we use className to assign CSS classes. class is a JavaScript keyword, so JSX uses the DOM property name className.

<div className="card">
  Hello
</div>

6. What is React Fragment?

A Fragment lets a component return multiple elements without adding an unnecessary wrapper element to the DOM.

return (
  <>
    <h1>Title</h1>
    <p>Text</p>
  </>
);
Fragment groups elements without creating an extra HTML element.

7. Important JSX rules

  • Return one parent element or use a Fragment.
  • Close every tag: <img />, <input />.
  • Use className instead of class.
  • Use camelCase for many DOM properties and event handlers, such as onClick.
  • Use { } for JavaScript expressions.
  • Component names start with a capital letter.
Remember: JSX looks like HTML, but it follows JavaScript/React rules.
